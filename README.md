# Palmer Penguins - Statistical Analysis
## Project description
A comprehensive statistical analysis of the Palmer Penguins dataset, built using R and RMarkdown.
This was developed as an academic project in collaboration with my friend. The goal of the study is to analyze and model the geographical and physiological differences among three penguin species (Adelie, Chinstrap, and Gentoo) in the Palmer Archipelago, Antarctica.

The presentation of the resuts is written in Polish and will be translated into English in the future.

## Analyses Performed
- **Data presentation and visualisation:** Visualizing distributions of physical traits across species, islands, and sexes.
- **Chi-Square Test of Independence:** Examining the correlation between penguin species and their geographical locations.
- **ANOVA Test:** Assessing the impact of location on the body mass of Adelie penguins (including Shapiro-Wilk for normality and Bartlett's for homoscedasticity).
- **Mann-Whitney Test:** Investigating sexual dimorphism based on bill depth and length.
- **Multiple Linear Regression:** Building a predictive model for penguin body mass based on flipper length, bill length, species, and sex.

## Technologies Used
The project was created using:
- **Languages**: R, RMarkdown
- **Packages**: `tidyverse` (`ggplot2`, `dplyr`, `tidyr`), `knitr`

## Data Source
The dataset used in this analysis was collected by Dr. Kristen Gorman and the Palmer Station, Antarctica LTER, and was sourced via [Kaggle](https://www.kaggle.com/datasets/larsen0966/penguins).
